# Remote Tab Overview

The **Remote** tab allows the radio to be fully controlled from within the RMS.  
The left side of the tab displays a live remote view of the radio’s screen, while the right side presents a button panel that mirrors the radio’s keypad and function keys.

---

## Starting a Remote Session

To start a remote control session:

1. Toggle the switch located beneath the **S2** button to the **On** position  
2. When the connection is successful, the status bar will display **“Remote Started”**

Starting the remote session does **not** automatically refresh the screen. If the display does not appear immediately, open the radio’s main menu and then close it to force a screen refresh.

---

## Remote Operation

Once connected:

- Clicking buttons in the RMS behaves exactly as if the corresponding physical key were pressed on the radio
- All changes to the radio’s display are reflected in the remote viewer
- The radio’s physical keys remain fully usable during remote operation

The **mouse wheel** is mapped to the **UP** and **DOWN** keys:
- Scrolling up acts as **UP**
- Scrolling down acts as **DOWN**

---

## Keyboard Shortcuts

In addition to mouse interaction, the following keyboard shortcuts are available:

| Keyboard Key                     | Radio Button |
|----------------------------------|--------------|
| Cursor Up Arrow / Page Up        | UP           |
| Cursor Down Arrow / Page Down    | DOWN         |
| Enter / Return                   | GREEN        |
| Escape / Backspace               | RED          |
| 0–9 (including numeric keypad)   | 0–9          |
| Spacebar                         | PTT          |
| Tab (and `#` on UK keyboards)    | #            |
| Period / Multiply / Asterisk     | *            |
| F1                               | S1           |
| F2                               | S2           |
| F3                               | EMG          |

## Note Regarding PTT Usage with the Remote

The radio emits a significant amount of RF energy during transmission. This energy can interfere with nearby electronic devices in a manner similar to an EMP, potentially causing instability.

Possible effects include:

- Computers or laptops freezing, crashing, or restarting  
- USB serial interfaces malfunctioning or disconnecting 
- Keyboards and mice becoming unresponsive
- Other unpredictable behaviour in nearby electronics  

If issues occur when engaging PTT via the remote interface, RF interference is the most likely cause.

To reduce these effects:

- Increase the distance between the radio and your computer or laptop  
- Use ferrite clamps on the USB programming cable  
- Use an external cable fed antenna rather than one mounted directly on the radio.
- Use a lower power setting
