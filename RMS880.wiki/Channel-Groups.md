# Channel Groups Overview

Each of the 999 pre-programmed channels can be organized into groups (_sometimes referred to as zones_) to simplify navigation and management of channels with similar characteristics.  

There are 26 available groups, labelled A through Z. Letters are used instead of numbers to avoid confusion with channel numbering. Each channel may be a member of up to four groups.  

## Adding or Removing Group Membership
**On the Radio:**
* Enter Channel Mode
* Navigate to the channel you wish to modify
* Open:  
  > [Main Menu → CMS → Add Group](https://github.com/nicsure/RMS880/wiki/CMS-Menu#add-group--rem-group) - to add the channel to a group, or  
  > [Main Menu → CMS → Rem Group](https://github.com/nicsure/RMS880/wiki/CMS-Menu#add-group--rem-group) - to remove the channel from a group
* Select a group letter (A–Z) and press GREEN to confirm (or RED to cancel)
The Extra Info field in the menu displays the current group membership of the active channel.

**Using RMS:**  
To edit channel group membership using the Radio Management Software, see: [RMS → Channels](https://github.com/nicsure/RMS880/wiki/Channel-Tab)
  
## Renaming Groups
Each group can be assigned a custom name of up to 12 characters.  
  
**On the Radio**
* Enter Group Mode
* Select the group you wish to rename
* Open [Main Menu → CMS → Group Name](https://github.com/nicsure/RMS880/wiki/CMS-Menu#group-name)
* Press GREEN to begin editing the group name
* Press GREEN to confirm once editing is complete
* Or press RED to cancel  
Text entry follows the standard T9 input method. See: [Radio → T9 Text Entry](https://github.com/nicsure/RMS880/wiki/T9-Text-Entry) 
  
**Using RMS**  
To rename groups using RMS, see: [RMS → Groups](https://github.com/nicsure/RMS880/wiki/Groups-Tab)
  
## Using Groups
Once channels have been organized into groups, they can be accessed using Group Mode.  
  
To enter Group Mode:
* Press RED to cycle the active VFO’s operating mode  
(_or #, depending on [Main Menu → Advanced → #/Red Mode](https://github.com/nicsure/RMS880/wiki/Advanced-Menu#red-mode) ) 
* You are in Group Mode when:
  > The channel number is displayed in yellow  
  > The selected group’s name is visible in the VFO display
  
# Group Mode Behaviour
Group Mode operates similarly to Channel Mode, with the following differences:
* Only channels that are members of the selected group are available
* The # and 0 keys cycle the selected group up or down
* Starting a scan (default: LP-3) scans only channels within the selected group
* The selected group can also be changed using LP-# (default) and entering a number:
  > 1 = A  
  > 2 = B  
  > 3 = C etc..
