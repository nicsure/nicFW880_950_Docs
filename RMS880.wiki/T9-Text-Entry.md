# T9 Text Entry Overview

Some radio settings and configurations require text input. Text is entered using a **T9-style input method**.

When a text field is active, an input box with a cursor is displayed. Use the **UP** and **DOWN** arrow keys to move the cursor right and left, respectively. Use the numeric keypad (**0–9**) to cycle through the characters available for the current cursor position, following standard T9 key assignments. Use `*` and `#` to enter their respective characters.

For multi-line inputs, the side buttons S1 and S2 can be used to move the cursor up or down a line.

After typing, the cursor can automatically advance to the next position once key presses stop. This behaviour is controlled by the **T9 Advance** setting:

- If **T9 Advance** is enabled, the cursor will move forward automatically after the configured delay.
- If **T9 Advance** is disabled, the cursor will remain in place until moved manually.

See: [Main Menu → Advanced → T9 Advance](https://github.com/nicsure/RMS880/wiki/Advanced-Menu#t9-advance)

Press **GREEN** to confirm the entry.  
Press **RED** to cancel the entry.
