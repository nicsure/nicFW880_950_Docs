# Band Plan Tab Overview

The **Band Plan** defines a set of preconfigured frequency bands that apply default settings and behavior to any frequency that falls within their defined ranges.

This tab is the RMS equivalent of the radio’s **Band Plan** menu.

---

## Band Slots

On the left side of the tab is a list of **20 band plan slots**, numbered **0 through 19**.

Selecting a slot from the list populates the controls on the right side of the tab. These controls allow you to edit the parameters that define how the radio behaves when operating within that frequency range.

---

## Deleting a Band Slot

To delete a band slot, set its **Start** frequency to **0**.  
This effectively disables the slot.
