# Startup Tab Overview

The **Startup** tab allows you to customize the image displayed when the radio powers on.

The boot image may be in any common image format, but it **must be exactly 240 × 320 pixels** to be accepted.

---

## Setting a Boot Image

To configure a boot image:

* Click the **Load Image** button and select a suitable image from your computer  
  - _A preview of the image will appear on the left of the window._
* Set **Logo Display Seconds** to define how long the image should remain on screen  
* Click **Write to Radio** to apply the image to the device  

The new boot image will be shown the next time the radio is powered on.
