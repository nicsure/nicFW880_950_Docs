# User Keys Tab Overview

The **User Keys** tab allows you to assign functions to key presses used in **Radio Mode**. This tab is the RMS equivalent of the radio-side **User Keys** menu.  
Each assignable key is listed along with a drop-down control. Use the drop-down to select the function you want to assign to that key.  
See:
 - [Main Menu → User Keys](https://github.com/nicsure/RMS880/wiki/User-Keys-Menu)

---

## Fixed Keys
The following keys have **fixed functionality** and cannot be reassigned:  
  
  
## **RT-880(G)**  
- SP-UP  
- SP-DOWN  
- SP-0 to SP-9  
- SP-RED  
- SP-GREEN  
- SP-*  
- SP-#  
  
  
## **RT-950 Pro**  
- SP-UP  
- SP-DOWN  
- SP-LEFT
- SP-RIGHT  
- SP-0 to SP-9  
- SP-GREEN  
- SP-ABC
- SP-VM
